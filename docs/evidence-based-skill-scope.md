# 经验候选的适用范围与负迁移

仍采用确定性 REMEDIES 与失败轨迹聚类，不宣称模型自主持续学习。候选来源增加 run/version/event_seq、投影/语义摘要、项目、固定 Git commit、fixture 标记、当时状态与验收结果；保留未修复和未验收轨迹，不仅选择成功。资源包含来源证据摘要，不含任务原文、隐藏测试、动作参数或模型私有正文。

新生成候选默认绑定来源 project/commit。普通任务在范围外选择技能时收到 SKILL_APPLICABILITY；显式实验允许在范围外测量，方便评估泛化与负迁移。一般上传的旧技能维持原有声明行为，不能因此认为有独立效果证据。

既有发布门禁继续要求真实模型、独立保留任务、相同 harness、单技能差异、记忆关闭、已结清费用与非劣/费用条件。带来源范围的新候选还要求分项目修复差值齐全，拒绝某项目明显下降被整体平均掩盖；这是已观察负迁移的阻断条件，不是分项目统计充分性的证明。缺失或负结果不能补成通过。

成功审核只扩展到该次评测实际绑定的项目和 commit；范围与评测摘要进入发布历史，最多 256 个绑定，继续扩展需新版本。回退恢复被审核版本的范围与证据，原来的灰度分配与退役功能保留。已发布内容不替代权限、预算与独立验收。

本轮仅本地机制回归；尚无真实失败轨迹候选的独立收益、灰度收益或负迁移统计报告。下一步需要有环境的外部任务 pilot，记录全成本及失败后再决定哪些候选值得发布。
