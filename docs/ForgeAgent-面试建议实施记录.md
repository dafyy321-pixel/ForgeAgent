## 第二部分：仓库接入

- 独立 SHA256 寻址的流式 bundle PUT，API/Nginx 16 MiB 上限；元数据仍为 2 MiB。按摘要与实际大小引用，不接受任意对象路径。
- CLI 先本地 Git/大小预检，`--dry-run` 不上传；正常登记先上传再服务端预检。
- 控制台接入向导要求固定 commit、bundle、受审验收/依赖 JSON；预检与真正执行验收分开显示。
- 复用既有展开大小、文件语义、锁文件/镜像与隐藏验收保护；[操作说明](project-onboarding.md)。真实沙箱试跑待环境，未标通过。

## 第三部分：历史查询与测量

- 0009 提交阶段持久 revision，替代多表哈希；事务回滚和正文编辑回归。
- SQL LIMIT 1 选择兼容 checkpoint；记忆在 SQL 筛 active/project；运维统计与 ID 上限。
- 对象发布移到租户知识生命周期锁之前，随后复核授权；仍保留幂等键锁。尚未将全部同步调用的 I/O 移出事务。
- 新增可复现历史读路径 pilot 和原始报告，[测量边界](history-performance.md)。61 项相关回归通过，历史查询新增 2 项通过。20 任务调度在共享主机曾单独通过（41.92 秒），但最终版本重复触及现有 45 秒时限；主机观测 CPU 100%。保留该未通过项，最终回归继续检查，不通过放宽超时隐藏负结果。测试观察器改为批量读取相同任务与同一数据库时钟，保持并发和完成断言。
