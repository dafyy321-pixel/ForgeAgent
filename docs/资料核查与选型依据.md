## 设计建议与事实的界限

下列均为本项目建议，不能冒用成论文原结论：七模块划分、PG Kernel 选型、状态枚举、29 张逻辑表、租约/心跳秒数、上下文阈值、子任务并发数、故障测试次数、非劣界、16–24 人周估计及性能目标。

自研 Kernel 的依据是研究项目需要直接控制 Agent 执行边界。若目标改成尽快交付业务产品，复用 DBOS/Temporal 更合适；应替换调度所有者而不是叠加两套恢复逻辑。

所有论文性能数字属于各自模型、数据与环境。主方案不填造 ForgeAgent 成功率、成本下降、恢复率或已实现能力。

## 快照管理

`research/manifest.json`记录本次提取材料路径、来源 URL、字节数和 SHA-256。`langgraph-durability.md`为空文件，代表一次抓取失败，不是有效来源；`otel.md`为迁移提示，实际字段核查使用 `otel-current.md`。

这些材料用于追溯和研究，不是新产品文档入口。日常阅读只需要主方案与本文，避免重新把资料目录变成一堆同等重要的设计文件。
