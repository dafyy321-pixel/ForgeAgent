# Twitter / X-inspired ForgeAgent

Reference reviewed on 2026-09-22:

- https://github.com/ccrsxx/twitter-clone — MIT-licensed, archived Twitter clone. Its public README describes timeline, bookmarks, replies, responsive layouts, and theme customization. Used as a reference for the three-column navigation / feed / discovery information architecture and bookmark interaction. No source code, images, logos, or dependencies copied.
- https://github.com/cycleccc/twitter-clone — additional project found by parent research; README includes planned features. No source or assets reused.

Original ForgeAgent design translates the social feed into a local task activity feed. Real application state supplies tasks, approvals, costs, artifacts, and skill toggles. Social vanity metrics are deliberately absent. Feed bookmarks persist locally; share copies a local task URL. All execution is explicitly local demo state.
